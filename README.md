# WerWolv Documentation

The source for [docs.werwolv.net](https://docs.werwolv.net), including the ImHex and Pattern Language documentation.

## Development

Install dependencies and start the development server:

```bash
bun install
bun run dev
```

Create a production build with:

```bash
bun run build
```

Documentation pages live in `content/docs`, and their static images live in `public/assets`. Pages are discovered automatically from the MDX files generated by Velite; adding a new page under `content/docs` makes it routable and adds it to the docs navigation.

## GitBook Import

The migration utility converts a checkout of the former GitBook repository into this site's MDX structure. It preserves the published routes, rewrites internal links, converts GitBook-specific markup, and copies referenced assets under descriptive names.

```bash
python3 scripts/migrate_gitbook.py /path/to/Documentation
```

The importer replaces `content/docs` and `public/assets`, then validates all generated local page and asset links.

## Pattern Language Libraries

The `Update Pattern Language Documentation` workflow downloads the latest `plcli` artifact, generates API documentation from the libraries in `WerWolv/ImHex-Patterns`, and updates `content/docs/pattern-language/libraries`.

The conversion step can also be run locally with:

```bash
python3 scripts/generate_pattern_language_docs.py \
  --plcli /path/to/plcli \
  --patterns /path/to/ImHex-Patterns
```
